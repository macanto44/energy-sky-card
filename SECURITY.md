# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's security advisories](https://github.com/macanto44/energy-sky-card/security/advisories/new): what it is, how to reproduce it, and what it could let someone do. It gets an answer as soon as possible.

The card runs in your Home Assistant's dashboard and shows your entities' states and names, so text that reaches the page as HTML (an entity's name or state, a cell's name or icon, a config value) is what matters most.

## Supported versions

The latest release. Fixes ship as a new release, not as patches to older ones.
